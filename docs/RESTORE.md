# Резервные копии и восстановление

## Что копируется
- **Каждую ночь в 04:00** автоматически (расписание включается при установке и обновлении). Файл `…/backups/koreahub-full-ДАТА.tar.gz`: **база данных и все фото** в одном архиве. Хранится 14 дней.
- **Перед каждым обновлением** (`install.sh update`) делается такая же копия.
- Вручную в любой момент: `sudo bash /opt/korea-hub/install.sh backup`.

Папка копий: `/opt/korea-hub/backups` (доступна только root). **Копии лежат на том же сервере.** Если диск сервера погибнет, погибнут и они: раз в неделю скачивайте свежую копию на свой компьютер или в облако (`scp root@СЕРВЕР:/opt/korea-hub/backups/koreahub-full-ПОСЛЕДНЯЯ.tar.gz .`).

## Копия вне сервера (рекомендуется)
Ночная копия сама уходит на другой сервер, если настроено:
1. На сервере для копий создайте пользователя и папку, например `backup@host:/srv/koreahub`. Этому пользователю нужен только доступ на запись в папку.
2. Создайте ключ без пароля: `sudo mkdir -p /etc/korea-hub && sudo ssh-keygen -t ed25519 -N "" -f /etc/korea-hub/offsite_key`. Публичную часть (`/etc/korea-hub/offsite_key.pub`) добавьте в `~/.ssh/authorized_keys` пользователя `backup`.
3. В один файл запишите адрес: `echo 'backup@host:/srv/koreahub' | sudo tee /etc/korea-hub/offsite`.
4. Проверка: `sudo bash /opt/korea-hub/install.sh offsite`. Дальше каждая ночная копия отправляется автоматически.
Копии содержат персональные данные: храните их на сервере, к которому имеете доступ только вы.

## Как восстановить
1. Посмотрите список: `ls -lh /opt/korea-hub/backups`.
2. Выполните: `sudo bash /opt/korea-hub/install.sh restore /opt/korea-hub/backups/koreahub-full-ДАТА.tar.gz`.
3. Скрипт предупредит, что текущие данные будут **заменены**. Чтобы продолжить, напишите `ДА`. Перед заменой он сам сохранит текущее состояние отдельной копией (на случай, если вы ошиблись файлом).
4. Скрипт остановит сайт и бота, пересоздаст базу, загрузит данные и фото, запустит всё снова.
5. Проверьте: откройте приложение, зайдите в «Мои объявления», откройте несколько фото.

Старые копии только базы (`koreahub-….sql.gz`, делались до этой версии) тоже подходят: фото в них нет.

## Проверка, что копии действительно делаются
- `ls -lh /opt/korea-hub/backups | tail` — новые файлы каждую ночь, размер не нулевой.
- `cat /var/log/korea-hub-backup.log` — журнал ночных копий.
- Раз в месяц пробуйте восстановление **на другом сервере или в тестовой папке**, чтобы убедиться, что копия читается. Копия, которую ни разу не восстанавливали, не доказана.

## Если сайт не отвечает
Скрипт проверки сам пишет администраторам в Telegram («🔴 KOREA HUB не отвечает») после двух неудачных проверок подряд, и когда всё починилось («🟢 снова работает»). Для этого `ADMIN_IDS` в `/opt/korea-hub/.env` должны быть заполнены, а админы хотя бы раз написать боту `/start`.
- Состояние: `sudo bash /opt/korea-hub/install.sh status`
- Логи: `cd /opt/korea-hub && docker compose logs --tail=100 api`
- Журнал проверок: `/var/log/korea-hub-monitor.log`
