# KOREA HUB: ТЗ на пользовательскую часть (для разработчика)

**Для чего документ.** По нему можно пересобрать сайт и Mini App для посетителей. Он описывает то, что видят и делают **люди**: экраны, поля, правила, тексты, справочники Южной Кореи, поиск, чат, знакомства, платные услуги, приёмку.
**Что не входит:** админ-панель (см. `docs/ADMIN-PANEL-TZ.md`), бот и связка с админкой (см. `docs/SITE-BOT-ADMIN-TZ.md`), детальный поиск (см. `docs/SEARCH-TZ-PL.md`, там пример под Польшу; правила для Кореи ниже в разделе 9).
**Эталон поведения:** текущая рабочая версия (репозиторий `schulzhikivan-hub/bottt`, ветка `korea-hub`). Где в документе написано «требование», а текущая версия этого не делает, это отмечено в приложении А.

---

## 1. Продукт

**Что это.** Сервис для русскоязычных людей в Южной Корее: вакансии, жильё, барахолка, авто, услуги, знакомства 18+, сообщество, справочник «как жить в Корее», личный кабинет, чат, оплата продвижения в Telegram Stars.

**Цели:** человек находит работу или жильё за минуты, не боится мошенников, публикует объявление за 3 минуты с телефона, получает ответ в Telegram.

**Принципы:**
1. Сначала телефон. Экран 360–430 px главный, компьютер вторичный.
2. Смотреть можно без входа. Вход спрашивается только на действие.
3. Меньше слов, больше структуры: плитки, чипы, карточки.
4. Любая ошибка объясняет, что делать, и даёт кнопку действия.
5. Безопасность видна: проверка модератором, жалоба в один клик, подсказки «не переводите предоплату».
6. Всё меняется без релиза: тексты, цены, справочники (через админку).

**Язык интерфейса:** русский. Тексты в коде и в БД хранятся так, чтобы добавить корейский и английский (все строки выносятся в таблицу переводов). Города, районы, станции, названия компаний показываются как введены автором; для поиска у городов есть корейские и латинские псевдонимы.

## 2. Платформа и режимы

| Режим | Как открывается | Вход |
|---|---|---|
| **Telegram Mini App** | кнопка «Открыть KOREA HUB» в боте, кнопка меню бота | автоматический по подписи `initData` (проверка HMAC-SHA256, не старше 24 ч) |
| **Сайт** (браузер, мобильный и компьютерный) | адрес сайта | гость; вход по кнопке «Войти через Telegram» (бот присылает подтверждение «Это я», сайт входит сам), сессия 30 дней |
| **Диплинки** | `t.me/бот?start=l_<id>` (объявление), `?start=src_<метка>` (источник), `?start=ref_<код>` (приглашение) | как выше |

Один и тот же интерфейс в обоих режимах. Единственный способ входа: Telegram. Паролей и e-mail нет.

## 3. Роли для пользовательской части

| Роль | Как получает | Что может |
|---|---|---|
| **Гость** | открыл сайт без входа | смотреть списки, карточки, гид, группы; искать; «Поделиться»; видеть цены |
| **Пользователь** | вошёл и принял правила | публиковать, откликаться, писать, избранное, жалобы, платные услуги, отзывы, знакомства |
| **Работодатель** | подал заявку, модератор подтвердил | значок «Проверенный работодатель», просмотр резюме, приглашения |
| **Проверенный автор** | отметка модератора | значок, публикация без очереди (если включено в админке) |

Права проверяются **на сервере** при каждом запросе. Скрытие кнопки не защита.

## 4. Вход, онбординг, профиль

### 4.1. Согласия (первое действие, требующее входа)
Окно «Добро пожаловать»: две обязательные галочки (пользовательское соглашение, политика конфиденциальности, оба документа открываются по ссылке) и кнопка «Продолжить». Версия согласия и время записываются. Без согласия нельзя публиковать, писать, оставлять отклики и оплачивать.

### 4.2. Приветствие
Один раз при первом открытии: заголовок и 3–4 строки «как это работает». Текст редактируется в админке. Закрывается кнопкой «Понятно» и больше не показывается на этом устройстве.

### 4.3. Город
Выбор города или района из справочника (раздел 8.3). Показывается в шапке, запоминается, влияет на выдачу и на рассылки.

### 4.4. Профиль
Аватар (буква или фото), имя (необязательное, видно только контрагентам, без ссылок, @ и телефонов), город, виза (скрыта, используется в фильтрах и откликах), счётчики (объявления, отклики, избранное).

### 4.5. Работодатель
Заявка: название компании, регистрационный номер (사업자등록번호, формат 000-00-00000), контактное лицо. Модератор проверяет. При отказе человек видит **причину**, может подать повторно. После подтверждения: значок «✔ Проверенный работодатель: <компания>» на всех вакансиях.

### 4.6. Данные
- **Выгрузка:** кнопка «Выгрузить мои данные» отдаёт JSON (профиль, объявления, избранное, платежи, отправленные сообщения).
- **Удаление аккаунта:** подтверждение, объявления скрываются, фото удаляются, имя и сообщения обезличиваются, согласие снимается; платёжная история остаётся обезличенной.

## 5. Навигация и каркас

### 5.1. Шапка (всегда сверху)
Логотип и название, слоган «Всё для жизни в Корее — в одном месте», выбор города, язык (RU), колокольчик уведомлений со счётчиком. Для гостя вместо профиля кнопка «Войти».

### 5.2. Нижняя панель (всегда снизу, 5 пунктов)
**Главная · Избранное · Добавить (выделена, круглая) · Сообщения · Профиль.** Панель закреплена, не двигается при прокрутке, не закрывает контент (внизу отступ). Для гостя «Избранное», «Сообщения», «Профиль» показывают **один экран входа**, а не пустой кабинет.

### 5.3. Карта экранов

| Код | Экран | Доступ |
|---|---|---|
| S01 | Главная | все |
| S02 | Раздел (Работа / Жильё / Барахолка / Авто / Услуги) со списком и фильтрами | все |
| S03 | Карточка объявления | все |
| S04 | Форма подачи (мастер из шагов) | вошедшие |
| S05 | Знакомства: список, анкета, моя анкета | вошедшие 18+ |
| S06 | Сообщество (группы) | все |
| S07 | Гид и статьи | все |
| S08 | Избранное | вошедшие |
| S09 | Сообщения: список и чат | вошедшие |
| S10 | Профиль (кабинет) и его подразделы | вошедшие |
| S11 | Уведомления | вошедшие |
| S12 | Платные услуги, оплата, история | вошедшие |
| S13 | Поддержка и вопросы-ответы | вошедшие (вопросы-ответы все) |
| S14 | Резюме («ищу работу») и поиск сотрудников | вошедшие / работодатели |
| S15 | Публичные страницы: объявление `/l/<id>`, разделы, правила, соглашение | все |

Кнопка «Назад» всегда ведёт на предыдущий экран (в Telegram включена системная кнопка «Назад»), позиция прокрутки списка сохраняется.

### 5.4. Состояния любого экрана
- **Загрузка:** серые «скелетоны» формы будущих карточек.
- **Пусто:** причина + одна кнопка действия.
- **Ошибка:** понятная фраза, кнопка «Повторить», код ошибки мелко; ошибка автоматически уходит на сервер.
- **Нет связи:** плашка «Нет связи с интернетом»; показываются последние загруженные данные.
- **Гость нажал личное действие:** окно «Войти через Telegram»; после входа действие продолжается.

## 6. Дизайн-система

**Только светлая тема** (по макету заказчика), цвета Telegram-темы не подмешиваются.

| Токен | Значение |
|---|---|
| Основной (бренд) | `#1b4b9b` (тёмно-синий) |
| Фон страницы | `#f3f6fb` |
| Карточка | белый, радиус 16–20 px, тень мягкая |
| Текст основной / вторичный | почти чёрный / серо-синий |
| Успех / внимание / ошибка | зелёный / оранжевый / красный |
| Акцент знакомств | розовый `#eb4f87` |
| Шрифт | системный (Inter / SF / Roboto), основной 16 px, подписи 12–13 px |
| Нажимаемые элементы | не меньше **44×44 px** |
| Поля ввода | шрифт ≥ 16 px (иначе iOS приближает) |
| Отступы | кратны 4 px; боковой отступ экрана 16 px |

**Компоненты (обязательный набор):** кнопка (основная, вторичная, опасная, ссылка), чип (фильтр, тег, статус), карточка списка (горизонтальная), плитка раздела, лист снизу (шторка), модальное окно, переключатель, выпадающий выбор, поле с подсказкой, скелетон, тост (короткое уведомление 3 секунды), плашка (ошибка, нет связи, версия), галерея с полноэкранным просмотром, бейджи (VIP, Проверенный, Новое, Закреплено, Резерв).

**Тексты ошибок:** по-человечески, без технических слов: «Не получилось сохранить. Проверьте связь и повторите» + кнопка.

## 7. Экраны

### 7.1. S01 Главная

1. **Поиск** (строка с подсказкой «Поиск вакансий, жилья, товаров и услуг…»), под ним подсказки при вводе (названия, города), последние 8 запросов.
2. **Баннеры** из админки (не больше 3 одновременно), могут быть с картинкой и ссылкой.
3. **9 плиток-разделов:** Работа, Жильё, Барахолка, Знакомства, Сообщество, Услуги, Автомобили, Виза и документы, Полезная информация. Плитка ведёт в тот же раздел, что и в меню.
4. **«Свежие вакансии»:** до 6 карточек (фото, должность, город, зарплата, график, «Жильё», бейджи VIP) + «Все вакансии».
5. **«Новые объявления»** из остальных разделов: до 6 карточек.
6. Строка доверия: «Объявления проверяет модератор. Пожаловаться можно в один клик».

Данные грузятся с сервера. Пустой город: «В Сеуле пока нет объявлений. Показать по всей Корее» + «Подать первое».

### 7.2. S02 Раздел и поиск

**Сверху:** название раздела, строка поиска, кнопка «Фильтры (N)» (число активных), сортировка.
**Чипы активных фильтров** со значком «×», кнопка «Сбросить всё».
**Список:** карточки по 20, кнопка «Показать ещё», сверху «Найдено: N».
**Фильтры** (лист снизу на телефоне, колонка на компьютере; результат пересчитывается по кнопке «Показать N»):

| Раздел | Фильтры |
|---|---|
| Общие | город / район, цена от-до (₩), только с фото, свежесть (24 ч / 7 дней / 30 дней) |
| Работа | зарплата от-до, период (месяц / день / час), занятость (полная / частичная / подённо / контракт), график (дневная / ночная / посменно), жильё предоставляется, питание, **виза** (множественный выбор из 11), «проверенный работодатель» |
| Жильё | тип (квартира, студия, комната, место в общежитии, офистель, дом), залог до, площадь от, комнаты от, с мебелью, можно с животными |
| Барахолка | категория (телефоны, электроника, мебель, бытовая техника, одежда и обувь, детские, инструменты, авто и мото, услуги, разное), состояние (новое / б/у) |
| Авто | год от-до, пробег до, марка, модель |
| Услуги | зона обслуживания, опыт |

**Сортировка:** «Новые» (по умолчанию), «Дешевле», «Дороже»; при текстовом запросе добавляется «По релевантности». Платные размещения всегда выше по правилам раздела 9.

**Сохранить поиск:** кнопка «Следить за этим поиском» → список «Мои поиски» (до 10, пауза, удаление, «Смотреть сейчас»). Без фильтров и слова сохранить нельзя.

### 7.3. Карточка в списке
Горизонтальная: слева фото 1:1 (96–110 px) или иконка раздела, справа: название (до 2 строк), цена жирным, город · «время назад», 2–3 параметра чипами, бейджи, сердечко «в избранное» (нажатие не открывает карточку). Платные: VIP (бейдж), «Закреплено» (над списком), «Выделено» (цветная подложка).

### 7.4. S03 Карточка объявления

| Зона | Содержание |
|---|---|
| Галерея | на всю ширину, свайп, счётчик «3/8», нажатие открывает на весь экран с увеличением и листанием |
| Шапка | цена, название, город · раздел · дата, «в избранное», «поделиться» |
| Параметры | сетка «ярлык: значение» (работа: компания, должность, занятость, график, виза, жильё, питание, мест; жильё: тип, залог, площадь, комнат, этаж, метро/станция, коммунальные; вещи: категория, состояние, бренд; авто: модель, год, пробег) |
| Описание | с переносами строк, длинное сворачивается |
| Автор | «✔ Проверенный работодатель/автор», «на сайте с 2026», «Все объявления автора: N», оценка и отзывы |
| Связь | нижняя закреплённая панель: «Написать» (чат), для вакансии «Откликнуться»; «Позвонить» и «Telegram автора» только если автор указал; контакт «Kakao» показывается текстом |
| Отзыв | кнопка «★ Оставить отзыв» только тому, кто переписывался; список отзывов с ответами автора |
| Похожие | до 6, та же категория, сначала тот же город |
| Жалоба | «⚑ Пожаловаться» → лист с причинами → «Жалоба принята» |
| Предостережение | рядом со связью: «Не переводите предоплату незнакомым людям» |
| Неактуально | плашка «Объявление неактуально» + похожие, а не пустая страница |

Предупреждения по разделам: работа «Платформа не гарантирует право на работу. Проверьте, разрешает ли ваша виза эту работу»; жильё «Платформа не проверяет права собственности и полномочия арендодателя».

### 7.5. S04 Форма подачи (мастер, 4 шага)

Индикатор «Шаг N из 4», «Назад», «Далее». Черновик сохраняется на устройстве и на сервере, при возврате предлагается «Продолжить незаконченное?».

| Шаг | Что |
|---|---|
| 1 | **Раздел и тип** (плитки), заголовок (3–160), город/район |
| 2 | **Параметры раздела** (обязательные отмечены ✱), цена (число + «договорная»/«бесплатно»), описание |
| 3 | **Фото** (до 10, первое обложка, перетаскивание порядка, удаление), подсказка «Хорошее фото = больше откликов» |
| 4 | **Контакт** (телефон / Telegram / Kakao), **предпросмотр** карточки, кнопка «Отправить на проверку» |

**Правила и проверки (сервер, мгновенно, с подсказкой что исправить):**
- Заголовок 3–160, описание до 4000, цена текстом до 80, контакт до 160.
- В описании запрещены телефоны, ссылки, @ники (контакт только в поле «Контакт»).
- Стоп-слова (предоплата, перевод на карту, USDT, залог за работу и т.п.) → отказ с пояснением.
- Жильё и вещи требуют минимум одно фото.
- Фото: JPEG/PNG/WebP до 8 МБ, меньшая сторона ≥ 80 px, соотношение сторон не более 5:1, EXIF и геометки удаляются, фото пересохраняются.
- Лимиты: 5 активных в одном разделе (30 у подтверждённого работодателя), новый аккаунт (первые минуты) 1 публикация в час, 10 публикаций в час максимум.
- Дубликаты текста или фото у разных авторов помечаются для модератора, автору не сообщается.
- Результат: «Объявление на проверке, обычно до суток»; кнопки «Подать ещё», «Мои объявления».

### 7.6. S10 Профиль (кабинет)

Для гостя: один экран «Личный кабинет — войдите через Telegram» с пояснением.
Для вошедшего:
- Шапка: аватар, имя, город, виза, «+ Добавить объявление», три счётчика.
- Меню: **Мои объявления**, **Мои отклики**, **Избранное**, **Сообщения**, **Недавно смотрел**, **Мои отзывы**, **Мои поиски**, **Пригласить друзей**, **Моё резюме**, **Найти сотрудника** (работодателям), **Настройки**, **Статус работодателя**, **История платежей**, **Заблокированные**, **Написать в поддержку**, **Вопросы и ответы**, **Правила**, **Выгрузить мои данные**, **Выйти**, **Удалить аккаунт**.
- Внизу номер версии сайта.

**Мои объявления:** вкладки по статусам, у карточки статус цветом, **причина отказа текстом**, «ещё N дней», кнопки по статусу:
- Черновик: «Отправить на проверку», «Изменить».
- На проверке: «Изменить».
- Опубликовано: «Изменить», «Продлить», «Статистика» (просмотры, избранное, чаты, отклики), «Закрыть», «Продано» (вещи), «Зарезервировано» (вещи), «Продвинуть», «Отклики» (вакансии).
- Отклонено / на доработке / скрыто: «Изменить», «Оспорить решение», «Удалить».
- Закрыто / продано: «Вернуть» (повторная проверка), «Удалить».
- Истекло: «Продлить».

**Продление (правило):** доступно за 30 дней до окончания или после него; прибавляет 30 дней к оставшемуся сроку, но не больше 60 дней вперёд от сегодня; завершившееся объявление возобновляется от сегодняшнего дня. Если рано, система говорит: «Опубликовано до 31.12. Продлить можно с 01.12».

**Редактирование опубликованного:** изменение заголовка, цены, фото, контакта или раздела отправляет **правку** на проверку, пока на сайте остаётся прежняя версия.

### 7.7. S09 Сообщения (по логике Авито)

**Список переписок.** Строка: фото объявления (или иконка раздела / 💗 для знакомств) с кружком-буквой собеседника, **имя собеседника**, название объявления · цена, последняя фраза («Вы: …» для своих), время (сегодня «15:35», вчера «Вчера», неделя «пн», дальше «12.11»), счётчик непрочитанных. Вкладки: **Все · Мне написали · Я написал(а) · Знакомства · Непрочитанные**. Снятое объявление: серая строка с пометкой «снято».

**Чат.**
- Шапка: стрелка, кружок с буквой, имя, статус («в сети», «был(а) недавно», «печатает…»), меню «⋯» (Скрыть чат, Заблокировать, Пожаловаться).
- Закреплённая **карточка объявления** под шапкой: фото, название, цена, «Открыть ›».
- Разделители дней («Сегодня», «Вчера», дата), пузыри, время, галочки «прочитано».
- Быстрые ответы: покупателю («Ещё актуально?», «Когда можно посмотреть?», «Можно ли снизить цену?», «Где вы находитесь?»), продавцу («Да, актуально», «Приезжайте, адрес пришлю», «Цена окончательная», «Уже продано»); в знакомствах нет.
- Ввод: фото, скрепка (PDF до 5 МБ, голос до 3 МБ), поле, справа микрофон (пока пусто) или «отправить» (когда есть текст).
- Правила: текст до 2000, 30 сообщений в минуту, фото до 8 МБ; один диалог на пару «человек + объявление»; «Скрыть чат» убирает его только у вас и возвращает, если вам снова пишут; вложения открывает только участник диалога.
- Для работодателя: приглашение из резюме открывает чат «по вашей вакансии».
- Уведомления об сообщении называют **кто и по какому объявлению**: «Борис пишет по объявлению «Диван»: …».

| Общение | `conversations` (+ `info`, `messages`, `photo`, `attachment`, `typing`, `status`, `hide`, `block`, `report`), отклики (`apply`, `me/applications`) |

| Деньги | `payments/invoice`, `me/payments`, `receipt`, `promo/check` |
| Доверие | `reports`, `reviews`, `tickets`, `resumes`, `me/referral` |
| Служебное | `client-log`, `health`, публичные страницы `/l/{id}`, `/c/{раздел}/{город}`, `sitemap.xml`, `robots.txt` |

Полное описание формируется автоматически (OpenAPI) и входит в передачу.
