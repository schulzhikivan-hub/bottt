# KOREA HUB — установка и обновление на VPS

Инструкция для установки на собственный сервер (VPS) через установщик `install.sh`.

---

## Быстрый старт: что куда вставлять

Понадобится телефон, приложение **Termius** (App Store или Google Play, бесплатное), IP-адрес VPS и пароль root из панели хостинга.

**Шаг 1. Подключитесь к серверу.**
В Termius нажмите «+» → **New Host**:
- Address: IP-адрес VPS
- Username: `root`
- Password: пароль root из панели хостинга

Нажмите **Connect**. Откроется чёрный экран с строкой вида `root@server:~#`. Это терминал сервера, все команды вставляются сюда.

Вставка в Termius: долгое нажатие на экране → **Paste**. После вставки нажмите Enter.

**Шаг 2. Введите токен GitHub (он невидим).**
Вставьте строку и нажмите Enter:
```bash
read -rs -p "Токен GitHub: " GH_TOKEN; echo
```
Курсор будет стоять на месте, символы не появятся. Это нормально. Вставьте свой токен (он начинается с `github_pat_`) и нажмите Enter.

**Шаг 3. Скачайте установщик.**
Вставьте строку и нажмите Enter:
```bash
curl -fsSL -H "Authorization: Bearer $GH_TOKEN" https://raw.githubusercontent.com/schulzhikivan-hub/bottt/korea-hub/install.sh -o install.sh
```

**Шаг 4. Запустите установку.**
Вставьте строку и нажмите Enter:
```bash
sudo bash install.sh install
```
Установщик задаст вопросы. Отвечайте по одному, каждый ответ вставляйте и нажимайте Enter:

| Вопрос | Что вставить | Откуда взять |
|---|---|---|
| Домен | например `app.example.com` | ваш домен, его A-запись должна указывать на IP VPS |
| Токен GitHub (невидимый ввод) | тот же токен `github_pat_...` | то, что вы получили на GitHub |
| Токен бота | `123456:ABC...` | @BotFather, команда `/newbot` |
| ID администраторов | ваше число, например `123456789` | @userinfobot |

Установка занимает 3–10 минут. В конце появится строка «Готово» и адрес Mini App.

**Обновление** (когда появится новая версия). Вставьте и нажмите Enter:
```bash
sudo bash /opt/korea-hub/install.sh update
```
Токен и остальные данные не спрашиваются: они сохранены на сервере.

**Если что-то пошло не так**, скопируйте последние строки вывода и пришлите мне.

## 0. Что нужно заранее

| Что | Зачем | Где взять |
|---|---|---|
| VPS на Ubuntu 22.04+ или Debian 12, от 2 ГБ RAM | Сервер приложения | Любой хостинг |
| Доступ root (SSH) | Установка Docker | Панель хостинга |
| Домен, например `app.example.com` | HTTPS для Mini App обязателен | Регистратор домена |
| Бот в Telegram и его токен | Работа бота | @BotFather |
| Ваш числовой Telegram ID | Права администратора | @userinfobot |

Порты на сервере должны быть открыты: **22** (SSH), **80** и **443** (HTTPS).

## 1. Бот в Telegram (BotFather)

1. Откройте @BotFather, отправьте `/newbot`.
2. Задайте имя (например, `KOREA HUB`) и юзернейм, оканчивающийся на `bot`.
3. Скопируйте токен вида `123456:ABC...`. Он понадобится в установщике.
4. Ваш Telegram ID узнайте у @userinfobot. Это число, а не юзернейм.

Токен не публикуйте и не отправляйте в чаты.

## 2. Домен

В панели регистратора или DNS создайте запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `app` (для `app.example.com`) | IP-адрес вашего VPS |

Проверка через 5–10 минут: `ping app.example.com` должен показывать IP сервера.

## 3. Установка

Подключитесь к серверу по SSH под root и выполните:

```bash
# Скачать установщик (если репозиторий публичный)
curl -fsSL https://raw.githubusercontent.com/schulzhikivan-hub/bottt/korea-hub/install.sh -o install.sh

# Запустить установку
sudo bash install.sh install
```

Репозиторий приватный, поэтому сначала создайте токен GitHub (раздел 3.1), а скачивание сделайте с токеном:

```bash
curl -fsSL -H "Authorization: Bearer ТОКЕН" \
  https://raw.githubusercontent.com/schulzhikivan-hub/bottt/korea-hub/install.sh -o install.sh
sudo bash install.sh install
```

Установщик задаст вопросы:
1. **Домен** — например, `app.example.com`.
2. **Токен GitHub** — из раздела 3.1. Ввод скрыт, на экране не появляется.
3. **Токен бота** — из шага 1.
4. **ID администраторов** — через запятую.

### 3.1. Токен GitHub для приватного репозитория

1. Откройте https://github.com/settings/personal-access-tokens/new (вход в аккаунт владельца).
2. **Token name:** `korea-hub-vps`.
3. **Expiration:** 90 дней (потом создайте новый и повторите установку или обновите файл токена).
4. **Resource owner:** `schulzhikivan-hub`.
5. **Repository access:** *Only select repositories* → выберите только `bottt`.
6. **Permissions → Repository permissions → Contents:** *Read-only*. Остальные права не нужны.
7. Нажмите **Generate token** и скопируйте его сразу: GitHub показывает токен один раз.

Токен никому не передавайте и не вставляйте в чаты и документы. Он сохраняется на сервере в `/root/.config/korea-hub/github_token` с правами только для root. Для обновлений установщик использует этот файл.

Если токен истёк или отозван, `update` выдаст ошибку доступа: создайте новый токен и запишите его в файл:

```bash
sudo bash -c 'read -rs -p "Новый токен: " T; echo; printf "%s" "$T" > /root/.config/korea-hub/github_token && chmod 600 /root/.config/korea-hub/github_token'
```

Отзыв токена: тот же раздел GitHub, кнопка **Delete**.

Пароли базы и админ-ключ генерируются автоматически и сохраняются в `/opt/korea-hub/.env` (доступ только root).

Установщик:
- ставит git и Docker, если их нет;
- клонирует код в `/opt/korea-hub`;
- создаёт `.env`;
- собирает и запускает контейнеры: базу, API, бота и Caddy (HTTPS);
- проверяет, что API отвечает.

Установка занимает 3–10 минут.

Чтобы пройти без вопросов, задайте переменные:

```bash
sudo DOMAIN=app.example.com BOT_TOKEN=123456:ABC ADMIN_IDS=111111111 bash install.sh install
```

## 4. Настройка Mini App в BotFather

1. @BotFather → `/mybots` → выберите бота.
2. **Bot Settings → Menu Button → Configure menu button**. Укажите URL: `https://app.example.com`.
3. Или через `/newapp` для отдельной карточки приложения (по желанию).

Проверка: откройте бота, нажмите `/start`, затем «Открыть KOREA HUB».

## 5. Проверка

```bash
sudo bash /opt/korea-hub/install.sh status
curl https://app.example.com/health
```

Ожидаемый ответ: `{"status":"ok","service":"korea-hub"}`.

Если HTTPS не отвечает сразу, подождите несколько минут: сертификат выдаётся при первом запросе. Проверьте DNS и порты 80 и 443.

---

## 6. Обновление

Когда появилась новая версия (зелёные проверки на GitHub), на сервере выполните:

```bash
sudo bash /opt/korea-hub/install.sh update
```

Что делает обновление:
1. Создаёт резервную копию базы в `/opt/korea-hub/backups/`. Если копия не создалась, обновление останавливается.
2. Получает последний коммит ветки `korea-hub`.
3. Пересобирает и перезапускает контейнеры.
4. Проверяет `/health`.

Файл `.env` не меняется. Данные базы сохраняются.

Если что-то пошло не так, предыдущая версия хранится в истории git, а база — в `backups/`.

---

## 7. Резервные копии

Вручную:

```bash
sudo bash /opt/korea-hub/install.sh backup
```

Копии хранятся в `/opt/korea-hub/backups/` 14 дней. Скопируйте их и на другой носитель: при потере сервера копии на нём тоже пропадут.

Восстановление:

```bash
cd /opt/korea-hub
gunzip -c backups/koreahub-ДАТА.sql.gz | docker compose exec -T db psql -U koreahub koreahub
```

## 8. Полезные команды

| Задача | Команда |
|---|---|
| Состояние сервисов | `sudo bash /opt/korea-hub/install.sh status` |
| Логи API | `cd /opt/korea-hub && docker compose logs -f api` |
| Логи бота | `cd /opt/korea-hub && docker compose logs -f bot` |
| Перезапуск | `cd /opt/korea-hub && docker compose restart` |
| Остановка | `cd /opt/korea-hub && docker compose down` (данные сохраняются) |

---

## 9. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Установщик: «Нужен домен» | Задайте `DOMAIN` или введите его в вопросе |
| Установщик: «API не поднялся» | `docker compose logs api`, проверьте `.env` |
| HTTPS не открывается | DNS A-запись, порты 80 и 443 в панели хостинга и в `ufw`, логи `docker compose logs caddy` |
| Бот не отвечает | `BOT_TOKEN` в `.env`, логи `docker compose logs bot` |
| Mini App открывается пустой | Адрес в BotFather совпадает с `DOMAIN`, HTTPS работает |
| Нужно изменить домен или токен | Отредактируйте `/opt/korea-hub/.env`, затем `sudo bash install.sh update` |

---

## 10. Безопасность

- Не выкладывайте `.env` и не отправляйте его в чаты.
- Закройте вход по паролю по SSH, используйте ключи.
- Включите файрвол: `ufw allow 22,80,443/tcp && ufw enable`.
- Админ-ключ `ADMIN_API_KEY` в `.env` нужен для API модерации. Меняйте его при утечке.
- Тестовые данные не храните в боевой базе.

## Вход в админ-панель

Адрес: `https://ВАШ_ДОМЕН/admin`

1. Откройте вашего бота в Telegram и нажмите `/start` (без этого бот не может написать вам).
2. На странице введите ваш Telegram ID (число из @userinfobot) и нажмите «Получить код».
3. Код придёт в Telegram от бота. Введите его на странице и нажмите «Войти». Код действует 5 минут и одноразовый.

Сессия живёт 12 часов. Первые администраторы — ID из `ADMIN_IDS` в `.env`, они получают роль Super Admin. Остальных добавляет Super Admin во вкладке «Сотрудники».

Роли:
- **moderator** — модерация объявлений и знакомств, жалобы, работодатели, блокировки;
- **admin** — всё от модератора, плюс цены, платежи и возвраты, статистика, статьи и группы, журнал;
- **super_admin** — всё, плюс управление сотрудниками.
