Установка VPS для TikTok

Удалённый рабочий стол на вашем VPS. Вы заходите в свой аккаунт сами, руками. Автопостинга и скриптов, которые имитируют действия, здесь нет.

Установка автоматическая. Вам нужно один раз добавить несколько секретов в GitHub и нажать кнопку. Всё остальное делает GitHub Actions на вашем VPS.

Что понадобится

ЧтоЗачем
VPS с Ubuntu 22.04, 2 ГБ RAM или большеНа нём будет рабочий стол и браузер. На 1 ГБ будет тормозить.
Данные от VPS: IP и root-парольПисьмо от хостера или панель управления
Приложение GitHubЧтобы добавить секреты и запустить установку
Приложение TermiusСоздать SSH-ключ (он нужен для входа на VPS)
Приложение TailscaleЗащищённый доступ к VPS с телефона
Приложение Microsoft Remote DesktopСам удалённый рабочий стол

Шаг 1. SSH-ключ в Termius

  1. Установите Termius, создайте аккаунт или войдите без регистрации.
  2. Откройте Keychain → Generate key → тип Ed25519.
  3. Откройте созданный ключ → Copy public key. Текст вида ssh-ed25519 AAAA… понадобится на шаге 3.

Шаг 2. Ключ для Tailscale

  1. Установите Tailscale на телефон и войдите (Google, Apple или GitHub).
  2. Откройте страницу ключей Tailscale → Generate auth key.
  3. Выключите Reusable и Ephemeral. Скопируйте ключ, он начинается с tskey-auth-.

Шаг 3. Токен для GitHub (для runner)

  1. Откройте создание токена.
  2. Token name: vps-bootstrap. Expiration: 7 days.
  3. Repository access: Only select repositories → выберите bottt.
  4. Repository permissions → Administration: Read and write. Metadata оставьте Read-only.
  5. Нажмите Generate token и скопируйте значение сразу: GitHub покажет его один раз.

Шаг 4. Секреты в GitHub

Откройте Секреты репозитория

Нажимайте New repository secret и добавьте шесть значений. Имена вводите точно так, как в таблице:

ИмяЧто вставить
VPS_HOSTIP-адрес VPS, например 203.0.113.10
VPS_ROOT_PASSWORDRoot-пароль от хостера
OWNER_PUBKEYПубличный ключ из Termius (шаг 1)
OWNER_PASSWORDПридуманный вами длинный пароль для входа по RDP. Сохраните его в менеджере паролей
TS_AUTHKEYКлюч Tailscale (шаг 2)
RUNNER_ADMIN_TOKENТокен GitHub (шаг 3)
Секреты нельзя посмотреть после сохранения. Если ошиблись, удалите и создайте заново.

Шаг 5. Запуск установки

  1. Откройте Bootstrap VPS
  2. Нажмите Run workflow, выберите ветку claude/telegram-bot-system-kssc6g и снова Run workflow.
  3. Подождите 5–15 минут. Зелёная галочка — установка прошла. Красный крест — откройте шаг с ошибкой и пришлите текст ошибки.
Если установка падает с Permission denied: хостер отключил вход root по паролю. Тогда пришлите текст ошибки, и мы переделаем вход на ключ.

Шаг 6. Подключение с телефона

  1. Проверьте, что runner появился: страница runner (статус Idle).
  2. Откройте Tailscale на телефоне. VPS появится в списке под именем vps-tiktok. Запишите его адрес вида 100.x.y.z.
  3. В Microsoft Remote Desktop добавьте ПК:
    • адрес: 100.x.y.z
    • пользователь: owner
    • пароль: тот, что вы задали в OWNER_PASSWORD
  4. В меню рабочего стола откройте TikTok (Chrome). Chrome откроет TikTok с сохранённым профилем.
  5. Войдите в аккаунт сами и включите двухэтапную проверку.

После установки

Уберите лишние секреты. Удалите RUNNER_ADMIN_TOKEN и VPS_ROOT_PASSWORD со страницы секретов. Токен можно отозвать на странице токенов.

Правила

  • Один VPS, один браузерный профиль, один аккаунт.
  • Не входите в аккаунт одновременно с телефона и с другого устройства.
  • Прокси, если нужен, задаётся в setup/settings.env, только для Chrome. Логин и пароль прокси в репозиторий не пишите.
  • Раз в неделю обновляйте систему и проверяйте активные сессии в настройках аккаунта.
