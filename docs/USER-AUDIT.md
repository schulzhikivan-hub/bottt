# Пользовательская часть: что работает криво и чего не хватает до идеала

Дата: 2026-11-01. Как смотрел: запустил сайт локально, прошёл на экране телефона (390×844) все пункты меню профиля, подачу объявления, кабинеты, чаты, поиск, «Мои объявления»; плюс чтение кода и результаты CI.

## 1. Найдено сегодня при реальном прохождении (исправлено)
- Первый вход: три окна подряд (приветствие, регистрация по e-mail, подсказка) закрывали экран.
- Счётчик «Сообщения» показывал число диалогов, а не непрочитанных.
- Просмотры считали автора, команду, сотрудников и роботов; повторные заходы засчитывались.
- Объявления компании попадали в личный профиль.
- Сортировка по цене ломалась поиском по слову и витриной.
- «Мои объявления»: длинный ряд из 11 кнопок под каждой карточкой.
- Пустое состояние в «Знакомствах» ломалось в узкую ячейку.
- Поля и кнопки «голого» браузера на экранах «Настройки», «Пополнение», «Компания», «Поиск сотрудников».

## 2. Найдено, но ещё не исправлено
- Кабинет знакомств: подписи в выпадающих списках обрезаются («Выберите реги…»), неровные отступы.
- Поля дат показывают формат браузера (mm/dd/yyyy), а не привычный дд.мм.гггг.
- Экран «Поиск сотрудников» для человека без вакансии даёт ошибку 403 в консоли; пользователь видит только подсказку.
- Подпись «Пользователь» в чатах, пока у человека нет имени.
- Нет значка/карточек для объявлений без фото: везде эмодзи-заглушки.
- Часть экранов (чаты, компания, знакомства) проверена только по скриншотам и тестам, не проходилась руками с реальными данными и оплатой.

## 3. Логика: чего не хватает
Объявления
- Откат к прежней версии; сравнение версий «было → стало».
- Подсказка цены по рынку; расписание публикации.
- Фото: нет единого экрана порядка и обложки в списке «Мои объявления» (обложка берётся первая).
Поиск
- Нет «рядом со мной», карты, сохранённых фильтров в профиле (есть сохранённые поиски).
- Нет исправления раскладки/опечаток в подсказках по объявлению (есть в поиске).
Чаты
- Нет поиска по чатам, закрепления, пересылки объявления, шаблонов ответов для компаний.
Компания
- Публичная страница без обложки и ссылок; нет шаблонов ответов; отзывы о компании отключены.
Деньги
- Нет пакетов продвижения и подписки «Про»; отчёты по обороту KH только в планах; подписи KH в админ-боте.
Аккаунт
- Нет письма подтверждения e-mail и восстановления пароля (нужна почта).
- Нет языков кроме русского.
Надёжность
- Поведение без сети/при сбое сервера проверено частично.
- Нет доступности (крупный шрифт, контраст) и проверки тёмной темы Telegram.
Рост
- Нет публичных страниц объявлений для поисковиков и красивого превью ссылок.

## 4. Порядок работ (предложение)
1. Исправить п. 2 (обрезанные поля, формат даты, 403, имена в чатах).
2. Пройти руками на сервере: вход, подача, правка, пополнение KH, покупка, компания, отклик, знакомства. Всё, что найдёте, сюда.
3. Откат версии объявления; подсказка цены.
4. Пакеты и подписка «Про» (деньги), отчёт по KH.
5. Публичные страницы и превью ссылок.
6. Языки, доступность, оффлайн.
