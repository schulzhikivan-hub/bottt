# Проверка в живом Telegram (iPhone и Android)

Автоматические тесты и проверка в браузере **не заменяют** эту проверку: только на телефоне видно, как приложение ведёт себя внутри Telegram. Проверьте на **iPhone и на Android**, в светлой и в тёмной теме Telegram. Отмечайте результат в колонке «ОК».

Подготовка: обновите сервер (`sudo bash /opt/korea-hub/install.sh update`), полностью закройте Mini App и откройте заново. Нужны два аккаунта Telegram (А — автор, Б — покупатель) и один аккаунт-администратор.

## Вход и оформление
| ОК | Проверка |
|---|---|
| ☐ | `/start` в боте показывает разделы кнопками; «Открыть приложение» открывает Mini App **внутри** Telegram |
| ☐ | Первый вход: окно «Добро пожаловать», без согласия писать и публиковать нельзя |
| ☐ | Нижняя панель (Главная, Избранное, «Добавить», Сообщения, Профиль) на месте и не двигается при прокрутке |
| ☐ | Шапка не уезжает; страница целиком не «ездит» при протягивании вниз |
| ☐ | Фон светлый по макету, в тёмной теме Telegram ничего не нечитаемо |
| ☐ | Кнопка «Назад» Telegram возвращает на предыдущий экран и закрывает открытые окна |
| ☐ | Клавиатура при вводе не закрывает поле и кнопки (форма объявления, чат, отклик) |

## Главная
| ☐ | Баннер и 9 плиток открывают свои разделы |
| ☐ | «Свежие вакансии» и «Новые объявления» загружаются, фото видны |
| ☐ | Поиск: подсказки появляются, нажатие на подсказку ищет |
| ☐ | Выбор города и колокольчик открывают свои окна |

## Объявление (аккаунт А)
| ☐ | «+» → Вакансия: все 4 шага, «Далее» подсказывает, чего не хватает |
| ☐ | Выбор фото из галереи и **со снимка камеры**; фото не повёрнуто боком |
| ☐ | «Сохранить черновик», закрыть, открыть снова: предложено продолжить |
| ☐ | «Опубликовать»: экран «Отправлено на проверку», в профиле «На проверке» |
| ☐ | Жильё и автомобиль без фото отправить нельзя; услугу и вакансию можно |

## Модерация (администратор)
| ☐ | `/admin` в боте: очередь, фото приходит картинкой, «Одобрить» работает |
| ☐ | Шаблоны причин отказа показываются кнопками; автор получает сообщение с причиной |
| ☐ | Веб-панель (`/admin`) входит по кнопке «Войти через Telegram» |

## Общение (А и Б)
| ☐ | Б открывает объявление А → «Написать»: сообщения доходят, у А приходит уведомление в Telegram |
| ☐ | Галочки «прочитано» меняются, фото в чат отправляется |
| ☐ | Б откликается на вакансию А; А приглашает с текстом; Б получает ответ |
| ☐ | Б отзывает отклик; закрытие вакансии А уведомляет Б |

## Оплата и звёзды
| ☐ | «Продвинуть»: витрина с ценами; промокод пересчитывает цену |
| ☐ | Оплата звёздами проходит, услуга включается, в профиле видно «до даты» |
| ☐ | Квитанция в «Истории платежей» открывается |
| ☐ | Возврат из админки: звёзды вернулись, услуга отключилась |

## Знакомства
| ☐ | Анкета с фото уходит на проверку; после одобрения видна другим |
| ☐ | Фильтры по возрасту и региону; «Меня лайкнули»; взаимная симпатия открывает чат |

## Бот
| ☐ | Разделы листаются в чате (◀ ▶), «В избранное», поиск словом, `/find слово` |
| ☐ | Ссылка «Поделиться» из объявления открывает бота с карточкой и кнопкой «Открыть в приложении» |

## Если что-то не так
Сделайте скриншот, запишите: устройство, версия Telegram, тема, что нажали, что ожидали. Номер запроса (`X-Request-ID`) и ошибки видны в логах: `docker compose logs --tail=100 api`.
