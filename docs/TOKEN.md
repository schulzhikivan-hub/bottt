# Замена токена бота

Токен бота — это пароль от бота. Замените его, если он попал в чат, в скриншот, в логи или к чужому человеку.

## Шаги
1. В Telegram откройте **@BotFather** → `/mybots` → ваш бот → **API Token** → **Revoke current token**. Старый токен сразу перестанет работать, BotFather покажет новый.
2. На сервере выполните: `sudo bash /opt/korea-hub/install.sh set-token`
3. Вставьте новый токен (при вводе он **не отображается**) и нажмите Enter.
4. Скрипт проверит токен у Telegram, запишет его в `/opt/korea-hub/.env` (права доступа только root) и перезапустит бота и сайт. В конце напишет имя бота, например `@korea_hub_bot`.
5. Проверьте: отправьте боту `/start`.

## Правила
- **Не присылайте токен в чат, в переписку, в репозиторий.** Токен нужен только серверу.
- Если токен уже попал туда, считайте его скомпрометированным и отзовите (шаг 1).
- Без терминала (автоматизация): `NEW_BOT_TOKEN='…' sudo -E bash /opt/korea-hub/install.sh set-token`.
- Токен не хранится в репозитории и не записывается в журналы приложения.
